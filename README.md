# Simple ATM System in Java

A console-based **ATM Simulation Application** built using Java. This project demonstrates core programming concepts including conditional logic, user input handling with `Scanner`, and state management via switch-case control flows.

## 🚀 Features
*   **Withdrawal:** Allows users to withdraw money with real-time balance validation.
*   **Deposit:** Enables instant balance updates upon adding funds.
*   **Check Balance:** Displays the current available account balance instantly.
*   **Pin Management:** Includes a placeholder option for changing the account PIN.

## 🛠️ Technologies Used
*   **Language:** Java (JDK 8 or higher)
*   **Core API:** `java.util.Scanner` for interactive user inputs.

## ⚙️ How to Run

Follow these simple steps to run the application on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project folder:**
   ```bash
   cd Simple-ATM-System-Java
   ```
3. **Compile the Java file:**
   ```bash
   javac ATMSystem.java
   ```
4. **Execute the program:**
   ```bash
   java ATMSystem
   ```
